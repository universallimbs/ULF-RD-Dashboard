# Bug Tracking Process

We use GitHub Issues for tracking R&D bugs and feature requests.

## Categories
- **Critical**: Prevents device assembly or operation.
- **Hardware**: Mechanical failure or 3D printing issue.
- **Software**: Dashboard or DAQ interface bug.
- **Clinical**: Safety concern or poor user fit.

## Reporting a Bug
1. Check if the issue already exists.
2. Provide steps to reproduce.
3. Attach photos or logs if applicable.
4. Assign to the relevant team lead (e.g., Rasna for strategy, Sahitya for coordination).
