# R&D Collaboration Rules

1. **Safety First**: All designs must undergo clinical review by Saja (Director of Prosthetic Services) before physical testing.
2. **Open Source**: All code and CAD files must be compatible with open-source licenses (GPLv3 or CC BY-NC-SA).
3. **Documentation**: Every design iteration must be logged in the Requirements Tracker.
4. **Data Privacy**: No patient-identifying information should be stored on public repositories.
5. **Repairability**: Designs must be repairable using locally available tools in resource-limited settings.
